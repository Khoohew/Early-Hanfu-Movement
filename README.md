# 邱少華與中國早期漢服運動個人歷史檔案

**時間範圍：** 2003—2007 年（初步整理）  
**檔案性質：** 個人歷史檔案、公開史料整理與口述史計畫  
**共同整理：** 邱少華與 AI 助手（包括 ChatGPT）

> 本檔案旨在保存早期漢服運動參與者的個人經歷、線下活動、網絡論壇交流及當年留下的媒體與網絡痕跡。所有內容均區分同期公開記錄、本人回憶、研究者整理及待核實事項，不以推測補全歷史。

## 史料標記

- **同期公開記錄：** 當年媒體、論壇或網站留下的資料。
- **本人確認：** 經邱少華本人確認的經歷或資料。
- **本人回憶：** 後續口述補充，尚未必有同期文件。
- **待核實：** 現有資料不足，或日期、地點、人物關係仍需確認。
- **研究整理：** 根據多份材料整理出的脈絡，不等同於原始史料。

## 重要原則

1. 不把媒體報導中的轉述自動視為本人逐字原話。
2. 不把論壇同名帳號在未核對前全部認定為本人。
3. 不把「曾發郵件聯絡」推斷成「本人曾到場」。
4. 日期、地點及參與人數以原始材料為準；有矛盾時保留差異。
5. 尊重第三方隱私與著作權。私人郵件、聊天記錄及他人個人資料，未經同意不公開。
6. GitHub 公開倉庫不是唯一備份；重要原始檔案應另存本地及其他備份位置。

## 共同整理說明

本專案由邱少華提供個人經歷、記憶及可能留存的原始材料，並與 AI 助手（包括 ChatGPT）合作進行公開資料檢索、史料比對、文字整理、翻譯及檔案維護。AI 整理內容仍須由本人核對；任何錯誤均應以原始史料及本人確認為準。
