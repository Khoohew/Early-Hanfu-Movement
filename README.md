# 邱少華的漢服運動歷史記憶檔案

**檔案性質：** 以時間軸為主線，回憶、梳理與記錄個人經歷中的歷史片段。  
**共同整理：** 邱少華與 AI 助手（包括 ChatGPT、Claude）

## 關於這份檔案

這是人生中一段重要的經歷。多年過去，許多記憶已逐漸模糊，不少曾經相識的人與經歷過的事，也慢慢淡出了記憶。

如今，我希望藉助當年保存下來的照片，以及其他零散資料，讓 AI 協助梳理、還原和整理這段過往。

這段歲月中，有些人成為了人生中的朋友，彼此見面不少，早已融入日常，不必逐一記錄；有些相遇則沒有留下任何痕跡，既無照片，也缺乏其他資料，今天已無從查證。

因此，這份檔案並不追求記錄所有人和所有事情，而是盡可能保存那些仍能找回的記憶與片段。

## 史料標記

- **同期公開記錄：** 當年媒體、論壇或網站留下的資料。
- **本人確認：** 經邱少華本人確認的經歷或資料。
- **本人回憶：** 後續口述補充，尚未必有同期文件。
- **待核實：** 現有資料不足，或日期、地點、人物關係仍需確認。
- **研究整理：** 根據多份材料整理出的脈絡，不等同於原始史料。

每段內容標示一次即可。新增記錄請使用 [事件記錄模板](TEMPLATE.md)。

## 寫作與考證方式

- 回憶部分用第一人稱，AI 考證部分用第三人稱。
- AI 考證註明由哪個 AI 整理及檢索日期，並區分同期報導與事後回顧。AI 的整理本身不算證據。
- 重要網頁連結盡量另存網頁存檔及本地副本。

## 重要原則

1. 不把媒體報導中的轉述自動視為本人逐字原話。
2. 不把論壇同名帳號在未核對前全部認定為本人。
3. 不把「曾發郵件聯絡」推斷成「本人曾到場」。
4. 日期、地點及參與人數以原始材料為準；有矛盾時保留差異。
5. 尊重第三方隱私與著作權。私人郵件、聊天記錄及他人個人資料，未經同意不公開。
6. GitHub 公開倉庫不是唯一備份；重要原始檔案應另存本地及其他備份位置。
7. 每一場活動盡可能獨立建檔，記錄日期、地點、參與者、活動經過、媒體記錄、照片及本人回憶。若一篇報導混合多個地點或活動片段，不擅自合併成單一場景。

## 共同整理說明

本專案由邱少華提供個人經歷、記憶及可能留存的原始材料，並與 AI 助手（包括 ChatGPT、Claude）合作進行公開資料檢索、史料比對、文字整理、翻譯及檔案維護。AI 整理內容仍須由本人核對；任何錯誤均應以原始史料及本人確認為準。
