# 網絡論壇與線上交流

本部分以邱少華本人的早期網絡經歷為中心，集中記錄曾接觸的網站、論壇、帳號、網友往來及線上活動。論壇背景與名稱考證作為輔助，不另行撰寫與本人經歷無關的論壇通史。

## 論壇與網站經歷

- [早期論壇與網絡社群：個人記憶及公開資料考證](forums-and-communities.md)

本文目前先整理四個網站／論壇：漢網、天漢民族文化論壇、華夏復興論壇、漢文化論壇。各項內容分別標示【本人記憶】、【公開資料】及【待核實】，隨本人補充記憶和後續查證逐步修訂。

## 後續可補充的線上經歷

- 各網站的接觸時間、網址、帳號及使用名稱
- 本人在論壇中的身份、版塊、發言和參與程度
- 認識的網友、線上交流及後來的線下往來
- 不同網站之間的交流、轉移、分歧或其他本人親歷事件
- 郵件列表、群組、即時通訊及私人通信（公開前須審核隱私）
- 網站關站前的備份、網頁存檔及網友保存的截圖

**整理原則：** 以重要的個人經歷為主，不為普通帖子單獨建立文件；除非某篇帖子本身具有明確的個人史料價值，才考慮另行保存。本人記憶與公開資料分開標示，不把同名帳號或後來文章的說法直接當作身份與經歷的證明。
