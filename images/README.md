# 圖片與影像資料

本資料夾用於保存與本專案相關的照片、論壇截圖及其他影像史料。

## 命名與整理原則

- 按「日期-英文簡述」命名，不使用空格，例如 `2004-10-10-jycg-forum-post.png`。
- 文件名盡量包含日期與簡短內容，避免使用含糊的 `IMG_001` 等名稱。
- 正文文章使用相對路徑引用圖片，例如：`![圖片說明](../images/檔名.png)`。
- 倉庫保存清晰、適合網頁瀏覽的 PNG 或 JPEG；原始檔由本人另存本地。
- 圖片說明在圖片下方用斜體書寫。上傳前遮蓋電話等私人資料。
- 圖片說明應標明日期、來源及核實狀態；未確認的資訊標註「待核實」。

後續新增圖片時按上述規則歸檔。
